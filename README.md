# Paste enabler

Cross-browser Manifest V3 migration of Chrome Web Store item `dhadehfniifbmemochpmbofcjckpdnnl`.

The project has moved from Plasmo 0.90.3 to WXT 0.21.3. React, Tailwind, Plasmo messaging, and Plasmo storage were removed because the small popup and content script do not require them. This substantially reduces the dependency and bundle surface while retaining Chrome, Edge, Firefox, and Safari builds.

Run `npm install`, then `npm run build`.
